# Sem 3 OOP Projects

A collection of college assignment exercises implemented using C++ Object-Oriented Programming (OOP).

## Projects

- **`employee.cpp` (Group A — Employee Management System):** Manages employee records using basic C++ OOP concepts.
- **`gB.cpp` (Group B — Student Result Management System):** Manages student marks across subjects (`EMMD`, `DSA`, `OOP`, `COA`) with file handling and exception handling.
- **`gC.cpp` (Group C — Library Management System):** Manages books using STL containers (`vector`, `map`), algorithms, and exception handling.
